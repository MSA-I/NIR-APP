# מרכז ההחלטות של InPlace

הכלי מיועד לבעל הפרויקט ואינו דורש ידע בתכנות.

## הפעלה

1. לחץ פעמיים על `START-OWNER-DECISIONS.cmd` בתיקיית הפרויקט.
2. ייפתח חלון שחור קטן ולאחריו הדף בדפדפן. השאר את החלון השחור פתוח בזמן העבודה.
3. בחר תשובה לכל שאלה. כל בחירה נשמרת מיד; אין כפתור “שמירה”.
4. אם אינך יודע עדיין, בחר “לא בטוח” או “צריך הסבר נוסף”. גם זו תשובה שנשמרת.
5. בסיום לחץ “סיימתי — מוכן לתכנון”, ואז כתוב לסוכן: “סיימתי את מסמך ההחלטות”.

## איפה התוצאות נשמרות

- קובץ לסוכן: `NIR-APP-DOCS\owner-decisions\current.json`
- סיכום קריא: `NIR-APP-DOCS\owner-decisions\current.md`

הקבצים נמצאים מחוץ לריפו. הם אינם מכילים סיסמאות, מפתחות או נתוני לקוחות.

## מה הכלי אינו עושה

- אינו משנה את `OPEN-DECISIONS.md` או את `DEBT-REGISTER.md`.
- אינו מתחבר ל־Supabase ואינו משנה Production.
- אינו שולח מייל, WhatsApp או בקשות לספק חיצוני.
- החלטה ישנה אינה נדרסת. “אני רוצה לשנות החלטה זו” יוצר בקשת שינוי חדשה ושומר את ההיסטוריה.

אם מסמך מקור השתנה, הבחירה הישנה נשמרת בנפרד והפריט מבקש ממך לבחור שוב מול הנוסח החדש.
