## ההנחה שאני עובד תחתיה, וצריך לדעת עליה

הריפו מצהיר בשלושה מקומות — `0006:27-31`, ‏`0151`, ‏`0153` — ש**חברות בצוות הפלטפורמה והקצאת
תפקידים נעשות מחוץ למערכת בכוונה, ואין להן דלת כתיבה ב-API**. הדרישה "ניהול מלא של משתמשים,
כולל צוות הפלטפורמה" הופכת את ההצהרה הזו. אני בונה את דלת הכתיבה, אבל רק בצורה הזו:

- יכולת נפרדת `operator.manage`, שמוקצית ל-`super_admin` **בלבד**.
- אימות מחדש של סיסמה (step-up) לפני כל שינוי, כמו כל פעולה בדרגת `high`.
- אסור לשנות את ההרשאות של עצמך — כדי שלא תהיה דרך להעניק לעצמך יכולת.
- אסור להסיר את מנהל-העל האחרון — כדי שלא תהיה דרך לנעול את כולם בחוץ.
- כל שינוי נרשם ביומן ייעודי, בלתי-ניתן-לעריכה, שהקונסולה מציגה.

אם ההיפוך הזה אינו רצוי — זו נקודת העצירה, לפני `G4`.
