### 2.3 יחידות מידה — `#282` — טבלת תרגום לתצוגה בלבד

`products.unit` **נשאר עברי**. אין מיגרציית נתונים. הערך העברי הוא המפתח, ושינויו נוגע
ב-`name_match_key` ובהתאמה המשולשת — התוכנית אוסרת זאת מפורשות (`PLAN §3.2`).

**מה כן:** מפה שנייה מהצורה הקנונית העברית לאנגלית, **מעל** `UNIT_FORMS` הקיימת
(`src/lib/format.ts:104`, ‏45 ערכים), ו-`Intl.PluralRules` לריבוי האנגלי.
`formatUnit(unit, quantity)` הוא נקודת הכניסה.

**התוצאה הנדרשת:** קורא אנגלי רואה `3 kg` · `12 units` · `2 crates`; מה שנשמר הוא `ק״ג`.
זה `P3-G2`, ו**הכשל הזה קיים כבר היום בפורטל** (`portal/i18n.ts:125` נופל ל-`unit?.trim()`).

**מלכודת:** ‏`check:money` מעריך **לפי שורה** (`scripts/check-money.ts:88-90`). פורמטר
שנשבר לשתי שורות חומק ממנו. כתוב בשורה אחת.

### 2.4 שפת העוזר — `#283` — לחבר את השפה לשרת

כל 15 נושאי העזרה קיימים בשתי השפות (`gate-i18n help-registry-paired`, הושג). **אבל
`profiles.locale` אינו מגיע ל-Edge Function כלל** — `get_product_help` מקבל `locale`

**מה נדרש:** העברת השפה מהלקוח אל הפונקציה, פריסה מחדש של פונקציית ה-Edge לפי מטריצת

**מה כבר נעשה ואינו מספיק:** תיאור הפרמטר שופר כך שיאמר למודל לבחור לפי שפת השאלה. זה

## 5. הכלל לבדיקות — התחדד, וזה חשוב

הכלל הקודם („אל תמחק את הטענה, העבר אותה עם המחרוזת") עומד. הסבב הזה הוסיף שלושה דפוסים:

**5.1 — הזרקת מתרגם עברי, כשה-spec בודק פונקציה.** ‏`model.spec`, ‏`filingReason.spec`,
`monthlyReport.spec` ו-`p2Reliability.spec` **שמרו כל assertion ללא שינוי** בזכות:
```ts
const t = ((key, vars) => translate(he as unknown as Dictionary, key, vars)) as
  (key: TKey, vars?: Record<string, string | number>) => string;
```
`confidenceLabel(0.97)` עדיין חייב להחזיר בדיוק `'זוהה בבירור'`. **השוואת `t(key)` מול
`t(key)` הייתה עוברת בין אם המילון נכון ובין אם לא.**

**5.2 — פיצול הטענה, כשה-spec סורק מקור.** שני חצאים, ואף אחד לבדו אינו מספיק:
```ts
expect(source).toContain("t('documents.text_72')");     // המסך מרנדר את המפתח
expect(he.documents.text_72).toBe('…העברית המדויקת…');  // והמפתח נושא את הנוסח
```

**5.3 — טענת היעדרות חייבת לחפש גם במילון.** ‏`accountantPaymentCredits.spec` בודקת
שהמסך **לעולם** לא אומר `סכום מאושר להעברה`. אחרי החילוץ **המילון הוא מקום שני שבו
הביטוי יכול להתחבא.** אותו דבר ב-`automaticReviewUx.spec`.

**5.4 — טענה על התנגשות תוויות חייבת להשוות מילים, לא מפתחות.** ‏`layout.spec` בודקת

1. **שם ספק, טקסט OCR, `audit_logs`, `comments`, מסמכי מקור — לא מתורגמים. לעולם.**
2. **הערות הן פרוזה על הקוד.** `t('ns.key')` בתוך הערה הוא נזק — שחזר מ-`git show`.
3. **`check:i18n` יכול רק לרדת.** ‏`--update` רק אחרי חילוץ אמיתי, באותו קומיט.
4. **אין „בוצע" בלי `npm run -s test` ירוק ו-`npx tsc --noEmit` נקי.**
5. **`git stash` אסור** — ה-worktree חולק את המחסנית עם סוכנים אחרים.
6. **סוכני משנה לא מריצים פקודות git שמשנות מצב.**
7. **חדש: `tsc` נקי אינו הוכחה שהמסך תקין.** ‏`TKey` הוא מחרוזת. כשאתה מעביר טבלה
   למפתחות, **שנה את שם השדה** — זה מה שמכריח את המהדר להראות לך כל אתר רינדור.
