### 2.1 ‏**חסום על אדם:** צילום מסך הבדיקה (חבילה E)

מודל ב-vitest. הוא **לא נפתח בדפדפן** בקמפיין הזה.

## 3. מלכודות שהסשן הזה שילם עליהן. אל תשלם שוב

### 3.1 מיגרציה בלי סוויטה היא מיגרציה שלא ידוע אם היא רצה

**שתי המיגרציות שנשלחו בסשן הזה בלי סוויטה — `0122` ו-`0123` — שתיהן היו שבורות.**

- ‏`0123`: ‏`attach_export_template_workbook` **מעולם לא רצה** — טריגר האי-שינויוּת של `0047` חוסם כל
  עדכון לשורת גרסה חוץ מזוג האישור. ‏p38 תפסה את זה בריצה הראשונה.
- ‏`0122`: כל העלאת צילום נדחתה, משלוש סיבות בזו אחר זו (§3.3).

השער הכבד בדק שהמיגרציות **הוחלו**. הוא לא בדק שהפקודות **רצות**.

### 3.2 הצבה מעוגנת חייבת לקרוא את סימן סוף השורה מהגוף

במסד הזה `document_export_template_contract_valid` נושא **LF** ו-`guard_document_export_template_version`
נושא **CRLF** — נוצרו מקבצים שנשמרו אחרת על מכונת Windows. עוגן עם `\n` בלבד מתאים על runner של
לינוקס ומחטיא כאן. הדפוס הנכון נמצא ב-`0126` §2 ו-§4:

```sql
v_nl := case when position(chr(13) in v_def) > 0 then chr(13) || chr(10) else chr(10) end;
v_old := replace(v_old, chr(10), v_nl);
```

זו אותה מלכודת של הצמדות `md5(prosrc)` (‏זיכרון `prosrc-hash-crlf-trap`), בכובע אחר.

### 3.3 מדיניות העלאה ל-Storage יכולה לקרוא רק את `name` ו-`bucket_id`

נמדד על storage-api 1.54.1:

- ‏`metadata ->> 'mimetype'` הוא **null** כשמדיניות ה-INSERT רצה. השירות ממלא `metadata` **אחרי**
  יצירת השורה. את הגבלת ה-mime שמים על `allowed_mime_types` של הדלי.
- ‏`owner` ו-`owner_id` **null** באותו רגע, מאותה סיבה.
- ההעלאה היא `insert ... on conflict ... RETURNING *`, ולכן הדלי **חייב מדיניות `SELECT`** או
  שההעלאה נכשלת ב-400. **דלי בלי מדיניות קריאה הוא דלי שאי אפשר לכתוב אליו.**

הדיאגנוזה: ‏`docker logs supabase_storage_supplyflow-p0` — ה-JSON נושא את ה-SQL המדויק תחת
`error.raw.metadata.query`.

### 3.4 סביבת Windows

- ‏**`.ps1` חייב BOM.** בלעדיו PowerShell 5 קורא אותו כ-ANSI וכל תו עברי בנתיב הופך ל-mojibake.
- ‏**צינור של PowerShell לתהליך מקורי משבש UTF-8.** ‏`Get-Content ... | docker exec psql` הפך שמות
  קטגוריות בעברית לאותה מחרוזת `?????` והפיל אילוץ ייחודיות. מ-bash: ‏`docker exec ... psql -f - < file`.
- ‏**`newline=''` בכתיבת קובץ קיים מפייתון.** ‏`newline='\r\n'` על מחרוזת שכבר מכילה CRLF יוצר `\r\r\n`.
- ‏`npm run quality` מקומי דורש `$env:SUPPLYFLOW_ALLOW_LOCAL_QUALITY = '1'`, ולפניו **לעצור את
  שרת ה-dev** (הוא מחזיק חיבור כותב ל-DB). הריצה שתועדה כאן עברה בדיוק כך.
- ‏**‏`deno.lock` בשורש** נוצר מהריצה המקומית. הוא ב-`.gitignore` מ-11.08 — הריפו מעולם לא נשא
  אחד, והוספתו הייתה משנה מה ש-CI פותר. אל תקמט אותו „לסדר".
