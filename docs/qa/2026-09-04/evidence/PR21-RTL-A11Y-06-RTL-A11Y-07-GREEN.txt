PR21 — RTL-A11Y-06 and RTL-A11Y-07
Rendered-pixel contrast, measured on the pixels the product actually paints.

HOW
  scripts/measure-composited-contrast.mjs, headed Microsoft Edge driven through playwright-core,
  1440x900, deviceScaleFactor 1, prefers-reduced-motion: reduce, signed in as the local demo
  owner through the login screen's own disclosure (no password is read, typed or printed).
  For every route and both themes the orb's centre is parked on the page description — the WORST
  position, and one every reader can reach, because the orb follows the pointer. The viewport is
  photographed twice: once as it is, and once with the measured text set to transparent colour.
  Every pixel of the second photograph inside a text box is the composited GROUND, and the
  verdict is taken on the worst of them, not on an average that would hide the dark end of a
  gradient. Integrity: hiding the text must CHANGE the box, or the capture is not showing what
  the page is showing, and the run aborts rather than reporting a comfortable number. (The first
  draft measured the modal colour of the box instead and aborted on its own check at the first
  route — 474x20 pixels held 849 distinct colours, because the ground is a radial gradient and
  has no single background pixel to find. That abort is why the method above exists.)

  src/pages/noDataMarker.spec.ts is the source half for RTL-A11Y-07: the mandated marker may not
  be drawn in a token the palette itself declares below AA. The exempt list is READ from
  scripts/contrast-pairs.mjs (ink-faint — "placeholder text and empty-state hints"; ink-ghost —
  "disabled lettering") rather than copied, so a token excused tomorrow is covered tomorrow.

WHAT IS NOT MEASURED, AND WHY IT IS SAID OUT LOUD
  /suppliers does not render against this machine's shared local Supabase stack. The stack sits
  at migration head 0245 while the tree carries 305 migrations up to 0314, so the screen's query
  names a column (suppliers.logo_path, added by migration 0275) the database has not got, and the
  page shows an error card with no heading at all. That is a fact about a stale shared stack, not
  a contrast result, and the run reports it as NOT MEASURED instead of quietly measuring thirteen
  routes and claiming fourteen. The four /suppliers markers are therefore closed by the source
  oracle above; the token they were moved to is measured live on /prices, which paints the same
  kind of table cell on the same ground.
