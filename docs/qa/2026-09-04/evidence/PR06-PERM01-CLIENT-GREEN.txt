WHY THE LAST ONE IS IN HERE. The bundle ships before the migration is applied, and for those
minutes `organization_people_directory` does not exist -- PostgREST answers 404 / 42P01. A roster
that depended on the view would be EMPTY rather than one column short, so the directory is an
enrichment and its error is deliberately not surfaced. The column is then ABSENT rather than a
dash in every cell, because a dash is a claim that nobody has a number on file, and that claim
would be false. Measured both ways: with the view present the colleague's 050-7654321 is drawn and
the column header exists; with the view absent the header is gone, the number appears nowhere, and
both people are still listed.
