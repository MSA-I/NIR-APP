WHAT THE GATE ASKS FOR, AND WHAT THIS CAMPAIGN DID INSTEAD
The gate's stated evidence is "`npm run next-number` output pasted into each PR that claims one,
drawn under the lock". This campaign centralised the draw instead: ONE holder
(.claude/locks/numbers, holder=session-cf142aac, the coordinator) draws, assigns each number to a
named PR in that file, and no agent may run `next-number` at all.

That is a deliberate deviation and it is stated here rather than glossed. The reason: pasting the
output into a PR proves the agent RAN the command; it does not prove that no other agent drew the
same number in the same minute. Six collisions in the 01.09 campaign were all of exactly that
shape -- each agent read the file, saw the highest number, added one, and three did it at once.
A single drawing authority removes the class; a pasted transcript does not.

The gate's INTENT -- no number is written before it is drawn, and no two writers get the same one
-- is what the evidence below is against.
