## 3. הצנרת — איך ממשיכים בפועל

ארבעה כלים, **מחויבים לריפו תחת `scripts/`** כדי שלא ילכו לאיבוד בין סוכנים:
`extract.mjs` · `apply-ns.mjs` · `wire-t.mjs` · `shoot-i18n.mjs`.

הקבצים הזמניים שהם מייצרים — `.tmp/pending/<ns>.json` (עברית) ו-`.tmp/en/<ns>.json` (אנגלית) —
**אינם בריפו**, וזה בסדר: הם תוצר ביניים של קובץ אחד. אחרי `apply-ns` התוכן חי במילונים.

### 3.1 `node scripts/extract.mjs <file> <namespace> [--write]`

מוצא עברית בקובץ, כותב מחדש ל-`t('ns.key')` ופולט את הצד העברי ל-`.tmp/pending/<ns>.json`.
בלי `--write` הוא רק מדווח. **תמיד הרץ קודם בלי `--write`** וקרא את שורת „left" — אלה
המקומות שהוא סירב לגעת בהם.

ארבעה כללים: מחרוזת בתוך attribute · מחרוזת בתוך ביטוי · טקסט בין `>` ל-`<` · **טקסט JSX
בשורה משלו** (הצורה הנפוצה ביותר בריפו הזה).

**מה הוא מסרב לעשות, בכוונה:** template literals, module scope, והערות. סירוב הוא לא כישלון —
**שכתוב שגוי במסך כספי עולה יותר מהחמצה.**

### 3.2 כתיבת האנגלית

קרא את `.tmp/pending/<ns>.json`, כתוב `.tmp/en/<ns>.json` עם **בדיוק אותם מפתחות**.

### 3.3 `node scripts/apply-ns.mjs <ns>`

מכניס את שני הצדדים למילונים. **מסרב אם מפתח חסר בצד אחד** — namespace מתורגם חלקית
מתקמפל ואז מציג מפתח למישהו.

### 3.4 `node scripts/wire-t.mjs`

מכניס `const { t } = useT();` לכל קומפוננטה שצריכה. **מונע על ידי המהדר** — הוא קורא את
פלט `tsc` ולא מנחש איפה קומפוננטה מתחילה.

> **מלכודת:** ‏`wire-t` מדווח „nothing to wire" גם כשקובץ **לא מתקמפל בכלל**, כי `tsc` מפסיק
> לפלוט `TS2304` ברגע שיש שגיאת תחביר. **פרסור נקי הוא תנאי מוקדם לאמון בו.**

### 3.5 המחזור המלא לכל קובץ

```bash
node scripts/extract.mjs src/pages/X.tsx nsname            # dry run — קרא את ה-left
node scripts/extract.mjs src/pages/X.tsx nsname --write
# כתוב .tmp/en/nsname.json
node scripts/apply-ns.mjs nsname
node scripts/wire-t.mjs
npx tsc --noEmit                                        # חייב 0
npm run -s test                                         # חייב 1,692+
node scripts/check-i18n.ts --update
git commit
```
