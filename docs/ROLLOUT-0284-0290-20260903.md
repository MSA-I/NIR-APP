## 4. ‏VPS — סדר שמצמצם את חלון אי-ההתאמה לשניות

2. **לפרוס את `document-processing`** (חוזה `3`). מכאן העובדים הישנים נכשלים.
3. **מיד: `docker compose … up -d`** — החלפת ה-containers לתמונה שכבר נבנתה. שניות.
4. **ראיה:** ‏`job_claimed` **ו-**`job_completed` ביומן אחרי ההחלפה, ו-`0` שורות
   `gateway_contract_mismatch`.

‏**החלפת subtree בלבד** — `git checkout origin/main -- worker/ocr`, לעולם לא `checkout` מלא:
אותו checkout מזין גם את שירות ה-render.

**שירות ה-render אינו נוגע ברולאאוט הזה:** ‏`worker/render` לא השתנה, החוזה `1` בשני הצדדים,
