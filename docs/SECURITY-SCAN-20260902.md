# סריקת אבטחה של כל האפליקציה — 02.09.2026

**מה זה.** סריקה סטטית של כל הקוד, בחמישה משטחים, על ידי חמישה סוכנים נפרדים: מסד הנתונים והרשאות
(‏RLS, ‏SECURITY DEFINER, אחסון), פונקציות ה-Edge (27), צד הלקוח והסודות, שני שירותי ה-VPS
(‏OCR ו-render), וזהויות ומפעילים. כל מועמד עבר מסנן עצמאי או אימות ישיר בכלי git ובקוד לפני
שנכנס לכאן; סף הקבלה 8/10. דוח Strix מאותו יום נבדק טענה-טענה; ההכרעות שלו ב-`§98`
ב-`DEBT-REGISTER.md` ובענף `fix/strix-security-findings` (PR #223), ואינן משוחזרות פה.

**השורה התחתונה.** לא נמצאה דרך שמשתמש של ארגון אחד יגיע לנתוני ארגון אחר, ולא נמצאו הזרקות.
תשעה ממצאים מאומתים: שלושה גבוהים, שלושה בינוניים, שלושה נמוכים; שבעה תקפים לייצור (ה-ledger
בייצור עומד על `0242`, ולכן כל מיגרציה אחרי זה היא `main` בלבד).

   בלוח הבקרה של Resend אם `supabase/functions/email-webhook/core.test.ts:36` מחזיק סוד אמיתי.
   אחר כך, במחשב הזה בלבד: `git reflog expire --expire=now --all` ו-`git gc --prune=now`.
2. PR #225 — משפחת `.env*` + השומר. PR #223 — ‏HTML/CORS/LIKE/SHA. PR #226 — ניקוי אסימונים.
3. מיגרציה `0285` — חמש פקודות `platform_*` דרך `private.assert_platform_command`, והצהרה שמונעת

## מה נבדק ונמצא תקין

- **מסד.** RLS על כל טבלה ב-275 המיגרציות; 181 מדיניות, כולן פרט ל-8 מוסברות מעוגנות
  ב-`org_id = auth_org()`; 700 הגדרות SECURITY DEFINER, לכולן `SET search_path`; מתוך 278
  שניתנות ל-`authenticated`, אפס נוגעות בטבלת דייר בלי תנאי `org_id`; אין SQL דינמי מקלט.
  ‏`guard_tenant_identity()` מכסה בדיוק 29 טבלאות (‏`0022:76-91`); שאר ~170 מוגנות ב-`WITH CHECK`,
  בהרשאות עמודה ללא `org_id` וב-67 מפתחות זרים מרוכבים `(org_id, id)`.
- **אחסון.** כל מדיניות כתיבה משווה את הרכיב הראשון של הנתיב ל-`auth_org()`; שלוש מדיניות קריאה
  משתמשות ב-join לשורה מסוננת במקום, ומוגנות ב-CHECK על `storage_path` (‏`0022:611`, ‏`0047:404`).
  ‏`organization-branding` ציבורי לקריאה **בכוונה**.
- **Edge.** כל ה-webhooks מאומתים ב-HMAC על הגוף הגולמי בהשוואה קבועת-זמן; שערי העובדים דורשים
  אסימון של 32+ תווים; כלי העוזר קריאה בלבד תחת JWT של הקורא; נתיבי אחסון נבנים בשרת.
- **VPS.** העובד מחזיק URL ואסימון בלבד ומסרב לעלות עם מפתח Supabase בסביבה; כל RPC מגודר על חכירה;
  ‏render מקבל נתיב בלבד על מקור קבוע.
- **לקוח.** אין `dangerouslySetInnerHTML`/`document.write`/`srcdoc`/`eval`; כל `VITE_*` ציבורי בכוונה;
  אין `service_role` בקוד הלקוח; Actions בלי `pull_request_target` ובלי סודות ריפו.
- **זהויות.** אימות מחודש נקרא מ-`auth.jwt()->'amr'`; תפקידים שפרשו מקבלים NULL ונחסמים בטריגרים;
  אסימוני הזמנה 32 בייט, sha256, חד-פעמיים; חוק דגלי התכונות נאכף מבנית (‏`0268:66-72`).
